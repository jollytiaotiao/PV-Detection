# Code Availability

The complete implementation of EDG-YOLO, including the MSGC, RGA, and SAE-IoU modules, training and evaluation scripts, configuration files, pretrained model weights, and dataset split files, will be released in this repository after the CSCWD 2027 review and publication process has been officially completed. The repository is currently reserved for project information, and the research implementation is temporarily unavailable in order to protect the unpublished method before the completion of the publication process.
